# Java CLI Library Management System

A Command-Line Interface (CLI) based library management system built in Java. This system allows users to borrow and return books, manage borrowing history, and interact with an administrator panel for adding, deleting, and updating books.

## Features

- **User Functionality:**
  - View all available books
  - Borrow and return books
  - View borrowed books and history
  - Search Book by its name or its ISBN
- **Admin Functionality:**
  - Add, delete, and update books
  - View borrowing history
  - View unreturned books

## Technologies Used

- Java (JDK)
- File-based data storage (JSON for books and borrowing history)
